## 🌟 TÍNH NĂNG NỔI BẬT

1. **📖 Hệ Thống Lý Thuyết Trọng Tâm (Knowledge Hub)**:
   - Tóm tắt 6 chương lý thuyết cốt lõi bám sát 184 slide bài giảng và giáo trình:
     - Chương 1: Tổng quan MPU/MCU, Cấu trúc Bus, Bộ nhớ, Kiến trúc ARM & Pipeline.
     - Chương 2: Phần cứng 89C51, Chân điều khiển EA/ALE/PSEN/RST, Cổng P0-P3, RAM nội 128 Byte, Vùng SFR, Mạch mở rộng RAM/ROM ngoài (74LS373 & 74LS138).
     - Chương 3: 5 chế độ định địa chỉ, 5 nhóm lệnh hợp ngữ MCS-51, Lệnh tra bảng MOVC, Vòng lặp DJNZ, Nhảy CJNE.
     - Chương 4: Bộ định thời / Bộ đếm (Timer/Counter 0 & 1), Thanh ghi TMOD, TCON, 4 chế độ Mode 0-3, Công thức tính thời gian trễ và giá trị nạp TH/TL.
     - Chương 5: Cổng truyền thông nối tiếp UART, Thanh ghi SCON, SBUF, PCON, Tính tốc độ Baud dùng Timer 1 Mode 2 với XTAL 11.0592 MHz.
     - Chương 6: Hệ thống ngắt, Bảng địa chỉ Vector ngắt (0000H, 0003H, 000BH, 0013H, 001BH, 0023H), Thanh ghi IE và IP.
   - **Sổ tay bấm máy Casio fx-580VNX**: Mode Base-N, chuyển đổi Hex/Dec/Bin, bù 2, đếm bit Parity, tính số xung đếm.

2. **🎯 Đấu Trường Luyện Tập Tự Do (Practice Arena)**:

     - 💡 Lời giải chi tiết từng bước & bản chất vi xử lý.
     - 📐 Phương pháp làm dạng bài tổng quát.
     - ⚡ Mẹo nhớ & Mẹo bấm máy tính Casio fx-580VNX.
   - Bộ lọc thông minh: Lọc theo Đề (Đề 001 - 005), theo Chuẩn đầu ra (CLO1, CLO2, CLO3), theo Part (Part 1 - 18), theo Trạng thái (Chưa làm / Làm đúng / Làm sai / Gắn sao ⭐).

## 🚀 HƯỚNG DẪN SỬ DỤNG

### Cách 1: Mở trực tiếp (Không cần cài đặt)
Chỉ cần nhấp đúp chuột vào file `docs/index.html` để mở ngay trên trình duyệt Chrome, Edge, Firefox, Cốc Cốc.

### Cách 2: Chạy Web Server cục bộ
```bash
# Sử dụng Python
python3 -m http.server -d docs 8000

# Hoặc sử dụng Node.js
npx serve docs
```
Sau đó truy cập: `http://localhost:8000`

### Cách 3: Kích hoạt GitHub Pages (Online Miễn Phí)
1. Đẩy mã nguồn lên repository GitHub của bạn:
   ```bash
   git remote add origin https://github.com/<tai-khoan>/<ten-repo>.git
   git branch -M main
   git push -u origin main
   ```
2. Trên GitHub, vào **Settings** -> **Pages**:
   - Tại mục **Build and deployment** / **Source**: Chọn **Deploy from a branch**
   - Branch: Chọn `main`, thư mục chọn `/docs` (hoặc `/ (root)`)
   - Bấm **Save**
3. Đợi khoảng 1-2 phút, trang web sẽ online tại: `https://<tai-khoan>.github.io/<ten-repo>/`
